One word that describes my Wi-Fi, for the Make.fun competition
"One Word for Your Wi-Fi".

## The word

**Goldilocks**

Why: Wi-Fi is never "just right". In the bedroom it's too weak, next to the
router it's too strong to need, and in the one chair where it works perfectly
you can never sit comfortably. Like Goldilocks, it keeps trying every spot
until it finds the one that's just right — and then someone walks past and
it leaves. It's funny, it's true of almost every home network, and as a
network name it's charming and memorable: "Goldilocks" is a name you'd
actually smile at seeing in your Wi-Fi list.

## Run

```bash
python3 main.py
cat /output/entry.txt
```

Writes the single word to `/output/entry.txt` and verifies it by reading it
back.
